The project

Schema Labs is building browser-local tools for engineers who work with JSON data contracts. The public developer preview combines JSON Schema validation with a conservative revision checker in a single workspace.

Schema Labs Ltd operates the Schema Labs website, documentation and public developer preview at schemalabs.co.uk. The product and contact address use the same domain.

What is available today

  • JSON Schema validation using Ajv.
  • Structural revision review with explicit severity labels.
  • Local JSON file input and downloadable check reports.
  • A browser worker that processes documents without sending them to a service.

This is an early developer preview, not a hosted enterprise platform. Account management, team workspaces and managed CI integrations are not offered in this release.

Development direction

We use Claude Code in our development workflow for implementation support, test coverage, and review of edge cases. It helped refine the current interface and exercise the browser-local checks. The next product work is clearer migration explanations and better handling of advanced schema composition.

Development tooling is not a runtime dependency. The current playground makes no Claude API calls. A future AI-assisted workflow would be opt-in, separately documented, and introduced only after cost and data handling are settled.
