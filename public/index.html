Revision review

Three labels. Each one says what to do next.

Comparison is directional: baseline to candidate. Every structural change is labelled by whether it narrows what the baseline used to accept.

Breaking
A recognized rule became more restrictive. Data the baseline accepted may now be rejected.
Example finding/properties/total/typeAllowed types narrowed.
Review
The effect needs a human decision. Changed advanced rules, such as composition, land here too.
Example finding/properties/status/enumEnum values were both added and removed.
Compatible
A recognized rule became more permissive. A local finding about that change, not a guarantee for the whole API.
Example finding/properties/status/enumAllowed enum values widened.

Payload validation

Test the payload against the contract.

Types, required fields, enums and constraints are checked by Ajv against JSON Schema 2020-12 or draft-07. Inputs are not coerced and missing fields are not filled in — a numeric string is still a string.

Built with restraint

A tool, not a black box.

Deterministic checks and explicit limits. This is what runs, where it runs, and what it leaves out.

Engine
Ajv, with JSON Schema 2020-12 and draft-07.
Where it runs
A browser worker in this tab. Documents are not uploaded.
References
Resolved within the document. Remote references are never fetched.
Limits
512 KB of UTF-8 per editor. A check past 8 seconds is stopped.
Advanced rules
Changed composition and other advanced rules are flagged for manual review.
Reports
JSON with findings, timestamp and mode — not your source documents.
Not included
Accounts, hosted CI pipelines or third-party data tracking.
Availability
Free to use as a developer preview.
